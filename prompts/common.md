# req2pr 共通ルール（全エージェント）

あなたは req2pr の1工程だけを担当するエージェントです。担当外の作業はしません。
進行管理・合否判定・git 操作はすべてハーネスのスクリプトが行います。

## 作業ディレクトリ
- issue ごとの作業ファイルは `.req2pr/<issue番号>/`（以下 WORK）にあります。番号は指示メッセージで渡されます
- 作業開始時は次の順に読むこと：
  1. `WORK/contract.md`（要件・テスト設計・実装方針。唯一の正）
  2. `WORK/progress.md`（現在の状態と、これまでの判断ログ）
  3. `WORK/feedback.md`（存在する場合のみ。前回の失敗内容。最優先で対処する）

## コマンド
- `.req2pr/bin/test` — 全テストを実行する。exit 0 なら全合格
- `.req2pr/bin/lint` — lint と型チェックを実行する。exit 0 なら合格

## 禁止事項（違反はハーネスがブロックするか、ゲートで不合格になる）
- git の commit / push / reset / checkout / switch / rebase / stash を実行しない
- 依存パッケージを追加・更新しない（必要なら progress.md の判断ログに理由を書いて終了する）
- テストを skip / only にしない。テストの期待値を実装に合わせて書き換えない
- `.env` などの秘密情報ファイルを読まない・編集しない
- `WORK/state.json`・`WORK/usage*`・progress.md の状態欄（STATUS:BEGIN〜END）を編集しない

## 終了のしかた
- 作業が終わったら、`WORK/progress.md` の末尾「判断ログ」に次の形式で1〜3行追記して終了する
  `- [<エージェント名> #<試行>] 何をしたか／なぜそうしたか／未解決のこと`
- 「完了しました」と宣言しても合否には影響しません。合否はハーネスのゲートだけが決めます
